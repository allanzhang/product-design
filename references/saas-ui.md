# SaaS Web 后台 UI 模式

适用于管理后台、内部运营工具、数据密集型 B 端应用。沿用宿主组件库（Ant Design / shadcn / Element 等）的既有组件与主题，只在其 token/主题层做定制，不并行造组件体系。

## 1. 应用骨架

- **左侧导航**：一级导航 ≤ 7 项；当前项用 `--primary` 文字色或 2–3px 左侧指示条 + 非颜色线索（字重/位置）；分组标题用 label 样式，不做成可点项。
- **顶栏**：页面标题/面包屑在左，搜索、通知、用户在右；不放营销内容。
- **内容区最大宽度**：数据表格/表单允许占满（12 列栅格），阅读型说明文字 6–7 列。
- 首屏即任务：禁止"欢迎回来 + 数据卡片大 hero"式开场。用户要审批就先看到待审批列表。

## 2. 列表页（最高频页面，解剖结构）

顺序固定：

1. **页头**：页面标题（说任务，不说模块名，如"待审批订单"而非"订单管理"）+ 主操作按钮（右上，每页最多一个主按钮）。
2. **筛选栏**：高频筛选（状态、时间、关键字）平铺；低频筛选收进"更多筛选"；已生效筛选以可删除的 chip 展示。
3. **数据表格**（主角，见 §3）。
4. **批量操作条**：勾选行后浮出，显示已选数量 + 批量动作；取消选择即消失。
5. **分页**：右下角；同时显示总数（"共 1,284 条"）。

空结果要区分三种：无数据（给创建入口）/ 筛选无结果（给清除筛选）/ 无权限（说明原因）。加载用**表格骨架屏**（表头 + 5–8 行灰条），不用整页转圈。

## 3. 表格

- 语义化 `<table>`；默认占满内容区宽度，禁止窄表格漂在宽区域里。
- 文本列左对齐、数字列（金额/数量/百分比）右对齐；**表头随列对齐**；用 tabular-nums。
- 行内单元格按首行文字基线对齐，不做垂直居中导致的错位。
- 行标签列给足宽度，短标签不换行；别让标签换行而旁边列空着。
- 同类数据单位、精度一致（金额统一两位小数或统一整数），不造假精度。
- 密度：普通业务表用舒适密度；只有高频查数场景（如库存盘点）用紧凑密度。
- 状态列：色点 + 文字（"● 待审批"），不用纯彩色文字。
- 操作列：放最后，主操作文字按钮 + 次要操作收进行尾"更多"菜单；危险操作（删除/驳回）在菜单内且需二次确认。
- 推荐/高亮行：只有业务规则支持时才高亮，不因"想让用户看到"而染色。
- 列太多时：先按用户查找任务重排列，再考虑横向滚动；禁止截断表头文字迁就布局。

## 4. 表单

- 标签在控件上方或左侧网格对齐；必填用 `*` + 表单开头说明，不用红色星号吓人但必须可被读屏识别。
- 错误信息归属到**字段下方**（红色文字 + 红框），不用页面顶部汇总弹窗；提交时滚动到第一个错误并聚焦。
- 单位写在输入框内后缀（如 `[ 8 ][ % ]`）或字段说明里，不写进 label。
- 数字输入用数字键盘语义（`type="number"` / 小程序 `type="digit"`）。
- 长表单分段（基础信息 / 商品明细 / 审批流程），每段一个用户问题；进度用步骤条，不用"第 3 步，共 5 步"之外的装饰。
- 放弃/重置有未保存改动时需确认；提交成功后给明确去向（"已提交，返回列表"或"继续添加"）。

## 5. 反馈四态（每个页面/组件都要过一遍）

| 状态 | 做法 |
|---|---|
| 加载 | 骨架屏为主；局部操作用按钮内 spinner；超过 3s 给进度提示 |
| 空 | 一句说明 + 一个下一步动作按钮；可配简洁插画（单色线性，不用彩色卡通大图） |
| 错误 | 操作失败说明原因 + 重试入口；表单错误归属字段；系统错误不暴露技术堆栈 |
| 成功 | toast 轻反馈即可；重要流程（下单、审批）用结果页/成功区显示关键信息（订单号、后续节点） |

toast 用于不需响应的轻反馈（3–5s 自动消失）；需要用户决策的用弹窗或内联区，不用 toast 承载。

## 6. 详情页

- 页头：对象标题（订单号用等宽）+ 状态徽标 + 主/次操作。
- 信息用**描述列表**（label 左、value 右，label 用 text-2）分组，不要每个字段套一张卡。
- 时间线/流转记录（审批流、物流）用竖向时间线，节点 = 状态色点 + 时间 + 操作人。
- 明细子表（订单商品行）用表格，金额右对齐，合计行加粗、置顶或置底保持一处。

## 7. 看板/图表

- 一屏回答一个问题；图表标题写成结论句（"本周订单量环比 +12%"），不是图表类型名（"柱状图"）。
- 趋势用折线/柱、占比用堆叠、对比用条形；所有条形共享零基线和同一刻度。
- 图表旁给一句 caption：该看什么、数据口径（时间范围/统计口径）。
- 核心数据卡（stat）：标签 + 大数字（等宽）+ 同比/环比小字；环比涨跌用语义色 + 箭头图标，不只染色。
- 图表提供明细数据表入口（数据是证据，图表是表达）。

## 8. 权限与角色

- 无权限的操作：**不显示**（而不是显示后点了报错）；只读用户的表单字段呈禁用态并说明。
- 审批/工作流类界面：当前节点、当前处理人、可执行动作三者必须同屏可见。

## 9. Web 响应式

- 桌面优先（B 端主战场），但 1280px 以下侧栏可收起为图标栏；表格在窄屏允许横向滚动而非挤压换行；长表单可堆叠。
- 栅格子元素给 `min-width: 0`，先重排再缩小。
