# 反模式清单（命名后才能规避）

交付前与 code review 时逐条对照。这些是 B 端产品 UI 中反复出现的"生成式设计默认坏味道"，每一条都给了可观察的判定方式。

## A. 信息架构与任务

1. **欢迎页开场（Welcome hero）**：首屏是"欢迎回来/系统名称 + 装饰大图 + 数据卡片堆叠"，而用户今天要处理的待办、待审批、异常被推到首屏以下。判定：首屏 3 秒内看不到当前用户的最高频任务入口。
2. **模板同质（Template silhouette）**：所有页面都是"页头 + 等宽卡片网格"，不管用户是来查数、审批还是录入。判定：两个任务完全不同的页面，区块轮廓一模一样。
3. **结论复读（Conclusion echo）**：摘要、图表、卡片、结论区重复表达同一个数字/结论。判定：同一答案在等高处出现两次以上。
4. **仪式化流程（Ceremony）**：表单/工具前放静态介绍页、"上一步/下一步"之外的说明页；操作后再放一个默认场景复述页。
5. **导航过载**：一级导航 > 7 项、分组标题做成可点项、面包屑超过 4 级。

## B. 色彩与表面

6. **彩色大爆炸（Color noise）**：中性色没有成为地基，状态色、品牌色、分类色铺满界面；价格被染成绿/红表示便宜/贵。判定：眯眼去色后信息层级崩塌，或一屏语义色 > 3 种含义。
7. **卡片套卡片（Nested panels）**：用边框修补弱层级，区块套区块、卡中卡；每个 metric 都装进独立卡片。
8. **装饰性表面**：渐变、渐变文字、辉光、玻璃拟态、条纹/网格背景、彩色侧边条、装饰阴影、假深度。
9. **图标彩色方块（Icon tiles）**：功能入口用大图标 + 彩色圆角方块拼网格；图标风格混用（线性/面性/填充混搭）。
10. **药丸标签滥用**：普通元数据、编辑性标签、图表注释都套 rounded pill。

## C. 表格与数据

11. **窄表漂移（Stranded table）**：宽表格被压缩在窄栏里、表头换行断词，或窄表漂在宽区域中旁边空着。
12. **数字不对齐**：数字列左对齐/居中、表头对齐方式与单元格不一致、未用等宽数字导致金额无法纵向比较。
13. **假精度与混单位**：同行金额有的两位小数有的整数；百分比与绝对值混在一列不标注。
14. **无刻度条形**：条形图每行各自为政、不共享零基线和刻度，条长度不编码数值；用条形轨道当分隔装饰。
15. **图例代替直标**：图表靠图例映射颜色而不是直接在图形旁标注；关键系列与辅助系列视觉权重相同。
16. **状态只靠颜色**：缺货/成功只用红绿文字，色盲用户无法区分；必须色点/图标 + 文字。

## D. 表单与反馈

17. **错误轰炸（Error dump）**：提交后页面顶部弹一长串错误，字段本身无标记；或静默重置用户输入。
18. **永久加载（Spinner forever）**：整页转圈无骨架；超过 3 秒无进度提示；加载失败没有重试。
19. **空状态死路**：空列表只显示"暂无数据"，不给创建/清除筛选/申请权限的下一步。
20. **危险操作无防护**：删除/驳回/撤销审批与普通操作同样式、无二次确认；或破坏性操作用主按钮蓝色。
21. **toast 承载决策**：需要用户处理的事项（审批结果、冲突提示）用 3 秒消失的 toast 一闪而过。

## E. 排版与工艺

22. **灰字塞密度**：用缩小字号 + 变灰来硬塞内容，而不是删内容/重排；正文行宽超过 68 字符或窄于 40 字符。
23. **角色不一致**：同类数字/标签在不同卡片里字号、字重、行高不一；只因字符串长就缩小字号。
24. **等宽滥用**：整段中文正文或整张表用等宽字体；等宽只应出现在订单号/SKU/ID 等标识符上。
25. **em dash 与全大写眉标**：标题用"——"凑节奏；全大写/加宽字距的 kicker、装饰性编号（01 / 02）当装饰。
26. **margin 打补丁**：用一次性 margin/transform 修错位，而不是修分组与间距归属。

## F. 小程序专项

27. **胶囊遮挡**：自定义导航栏内容与右上角微信胶囊重叠，或未按胶囊垂直对齐。
28. **Web 平移（Web ported）**：把 hover 效果、宽表格、多层弹窗、侧边抽屉照搬到小程序；宽表超过 3 列仍用 `<table>` 式布局。
29. **触控目标过小**：可点元素 < 88rpx 或间距 < 16rpx；底部按钮栏未留安全区。
30. **自绘原生能力**：自己做 picker 弹层、模态框、toast，而不用 `picker`/`wx.showModal`/`wx.showToast`；页面层级超过 10 层。
31. **setData 洪流**：一次 setData 传整棵大对象、长列表不分片，导致卡顿。

## G. 动效与内容

32. **默认喧闹**：自动轮播、打字机、脉冲呼吸点、hover 图片位移、视差、bounce 入场；阅读被动画遮挡。
33. **库存插画/假截图**：用 stock 配图、AI 装饰插画、假产品截图填充空位。
34. **过程叙事**：页面/回复里解释"本页面是如何组织的"、字段为什么改名——交付成果，不交付制作日记。

## 反向警告

规避以上不等于走向"黑白细线 + 大留白"的空洞反设计模板。B 端的克制 = 精确的任务层级、一致的排版角色、对齐的数据证据、明确的状态反馈，以及一个刻意的视觉锚点。检查"克制"时同时检查：页面是否因此变得平淡无重点？如果是，问题在层级与构图，不在颜色少。
