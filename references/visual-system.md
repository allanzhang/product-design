# 视觉系统 token（SaaS Web + 小程序通用）

本文件定义产品 UI 的唯一合法 token 集合。**不允许发明 token 之外的字号、字重、颜色、间距、圆角值。**
判断规则写在 SKILL.md；可重复机制全部沉到这里的 token 与组件里。

> 色彩体系严格遵循 Vercel/Geist design 规范（单色地基 + 四个语义角色 + 灰阶数据色），
> 色值提取自离线资产 `assets/vercel-brand.css` 的 Geist token（oklch 换算为 hex）。
> 品牌页/报告页直接使用 vbg-* token；本文件的 token 用于产品 UI。

## 1. 色彩

### 1.1 单色地基（Design in monochrome）

界面 95% 的面积是中性灰。Geist 中性色是**纯灰**（无色相），层级靠排版、留白、密度和边框建立，不靠颜色。

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--canvas` | `#FFFFFF` | `#000000` | 页面底色 |
| `--surface-1` | `#FFFFFF` | `#0A0A0A` | 卡片、弹窗、输入框（深色模式抬升面） |
| `--surface-2` | `#FAFAFA` | `#1A1A1A` | hover、次级容器、斑马行 |
| `--border-subtle` | `#E6E6E6` | `#212121` | 分隔线、表格线 |
| `--border-default` | `#EBEBEB` | `#242424` | 输入框默认边框 |
| `--border-strong` | `#8F8F8F` | `#828282` | 强调分隔、焦点对比 |
| `--text-1` | `#171717` | `#EDEDED` | 主文字 |
| `--text-2` | `#4D4D4D` | `#A0A0A0` | 次要文字、说明、label |
| `--text-3` | `#7D7D7D` | `#7D7D7D` | 占位符、禁用文字 |
| `--contrast-band` | `#171717` | `#EDEDED` | 反色区（深底浅字/浅底深字），内含色反转 |

规则：
- 优先用留白、对齐、密度变化表达层级，而不是边框和盒子；不要给每个区块套卡片，禁止卡片套卡片。
- 反色带（contrast band）只用于需要强对比的焦点区（如关键结论条），其内部文字/边框/控件颜色必须成套反转，不要在页面 CSS 里手拼深底。
- 商品图、照片是产品里唯一的"彩色区域"，趣味性由商品图片承载；UI 本身保持单色。

### 1.2 语义色（全系统只有四个颜色角色 + focus）

颜色只在表达**状态、操作或数据**时出现，且必须配非颜色线索（图标/文字）。Geist 语义色：

| 角色 Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--color-action`（蓝） | `#006BFF` | `#47A8FF` | 主按钮面、链接、选中态、focus ring、当前导航 |
| `--color-action-pressed` | `#005FF2` | `#006EFE` | 按下/hover 加深（浅） |
| `--color-success` | `#107D32` | `#00CA50` | 有货、已下单、已支付、审批通过 |
| `--color-warning` | `#AA4D00` | `#FF9300` | 库存紧张、待审批、临期 |
| `--color-error` | `#FC0035` | `#F13242` | 缺货、失败、驳回、表单错误、破坏性操作 |
| `--color-info` | = `--color-action` | = `--color-action` | 不另设颜色 |

状态浅底（chip/徽标背景，文字用对应语义色）：

| | 浅底 | 深底 |
|---|---|---|
| action | `#F0F7FF` | `#06193A` |
| success | `#ECFDEC` | `#002608` |
| warning | `#FFF6DE` | `#2A1700` |
| error | `#FFEEEF` | `#330A11` |

硬规则：
1. 每个语义色必须配**非颜色线索**：状态点 + 文字（"● 有货 / ● 仅剩 3 件 / ● 缺货"），不许只靠红绿传义。
2. **价格不染绿/染红**：价格高低、折扣不用颜色表达，用字重 + 等宽数字；优惠信息用文字标签（如"立减 ¥20"）。数字的涨跌用箭头图标 + 语义色，不只染色。
3. 一屏只有一个主按钮（action 蓝）；次级操作用描边/幽灵按钮；破坏性操作（删除、撤销审批、驳回）用 error 色 + 二次确认。
4. focus ring 统一 2px `--color-action`，不可去掉。
5. warning 的琥珀色在浅底 chip 上用深色文字（`#AA4D00`），不要在琥珀底上放白字。

### 1.3 数据可视化（默认灰阶，不是彩虹盘）

Geist 报告规范的图表色本身就是**灰阶**：默认系列用单色深浅区分，直接在图形旁标注，不用图例。

- 默认系列灰阶：`#171717` / `#4D4D4D` / `#7D7D7D`（深色模式：`#EDEDED` / `#A0A0A` / `#7D7D7D`），配合实线/虚线、粗细、直接标签区分。
- 只有当数据编码的是**状态**（成功/失败/待处理占比、阈值对比）时才引入 success/warning/error/action 蓝。
- 所有条形共享零基线和同一刻度；图表标题写成结论句，附口径说明（时间范围/统计口径）。
- 图表必须有明细表入口：数据是证据，图表是表达。

### 1.4 分类与标签

- 商品分类、tab、筛选标签等**结构性区分一律用中性样式**：`--surface-2` 底 + `--text-1` 文字，选中态用 `--color-action` 文字/指示条 + 字重（非颜色线索）。
- 不要为每个玩具分类发明一个彩色 chip——分类是导航结构，不是状态。颜色的泛滥会稀释语义色的信号强度。

## 2. 字体

- **正文/标题/数字**：无衬线。Web 用 Geist 或系统栈（`-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif`）；等宽用 Geist Mono 或 `"SFMono-Regular", Consolas, monospace`。
- **等宽**：仅用于订单号、SKU、批次号、物流单号、账号/环境 ID 等短标识符——**只把标识符本身设为等宽**，不是整句或整表。
- 数字一律 `font-variant-numeric: tabular-nums`（等宽数字），表格金额、数量、百分比必须对齐比较。
- 字重只用：regular(400) / medium(500) / semibold(600)。正文 regular，强调稀缺；不用 700+。

### 字号阶梯（Web / 小程序 rpx）

| 角色 | Web | 小程序(rpx) | 用途 |
|---|---|---|---|
| display | 32/40 | 56/72 | 仅限页面级唯一主标题，克制使用 |
| title | 24/32 | 44/60 | 页面标题 |
| heading | 18–20/28 | 36/52 | 区块标题 |
| body | 14–16/24 | 28–32/44 | 正文、表格、表单 |
| label | 13/20 | 26/38 | 标签、按钮、导航 |
| caption | 12/18 | 22/32 | 辅助说明、时间戳 |

禁止：用灰色小字硬塞密度（先删内容）；同行同类元素字号不一致；正文行宽控制在 60–68 字符（中文约 28–40 字/行）。

## 3. 间距与圆角

- 间距阶梯：`4 / 8 / 12 / 16 / 24 / 32 / 48`（小程序 rpx 同比例 ×2：8/16/24/32/48/64/96）。
- 圆角：小控件 6（rpx 12），卡片/弹窗 10–12（rpx 20–24）；全系统统一，不逐元素取值。
- 垂直节奏由"关系"决定：区块内小组件用小间距，区块间用大间距；不要用随意 margin 修补错位——去修分组和间距的归属。

## 4. 表面与边界

- 页面默认是一张连续画布。只有在表达**选中、交互、警告、对比、真实分组**时才用表面/边框。
- 禁止：装饰渐变、渐变文字、辉光、色块 blob、条纹纹理、网格背景、玻璃拟态、纸张质感、彩色侧边条、装饰阴影、假深度。
- 阴影只用于浮层（下拉、弹窗、tooltip）表达真实层级，且全系统一套。

## 5. 暗色模式

- 用同一套 token 名，双值切换；明暗两套层级与对比度必须等价（WCAG AA）。
- 产品 UI 可保留主题切换器；不允许明暗两套不同的信息层级。
- 深色模式语义色用高明度版本（见 1.2），状态色在深底上仍要配图标/文字。

## 6. 小程序落地

- 颜色 token 写在 `app.wxss` 的 `page{}` 或 CSS 变量中；暗色用 `@media (prefers-color-scheme: dark)` 或 `theme.json`。
- 字体族受限：只用系统字体栈，不引入外部 webfont（包体积与加载）。
